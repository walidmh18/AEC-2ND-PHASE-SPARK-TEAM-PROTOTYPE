1. FMEA RISK CALCULATOR
------------------------------------------------------------
Endpoint: POST /spark/fmea
Purpose: Maps 5 risk axes (1-3 scale) to determine the baseline validation plan.

[Request Body]
{
  "maturite_methode": 2,          // 1=High maturity, 3=Low maturity
  "complexite_matrice": 3,        // 1=Simple matrix, 3=Complex matrix
  "disponibilite_donnees": 1,     // 1=High availability, 3=Low availability
  "criticite_reglementaire": 2,   // 1=Low criticality, 3=High criticality
  "risque_patient": 2             // 1=Low risk, 3=High risk
}

[Response Body]
{
  "rpn": 10,
  "decision": "PLAN RÉDUIT (4 niveaux x 2 réplicats = 8 injections)"
}

------------------------------------------------------------
